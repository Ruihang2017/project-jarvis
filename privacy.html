Privacy Policy

Last updated: 2 October 2026

Summary

Jarvis is a personal assistant used by one person, its owner, on their own Windows computer. It has no servers and no other users. Google data is used only to do what the owner asks, and it never leaves the owner's computer except as described below.

Data Jarvis accesses

Only after the owner connects their Google account, and only within the permissions they grant:

  • Google Calendar: event titles, times, locations, attendees and descriptions, to show the schedule and to create or update events on request.
  • Gmail: message headers and content, to summarise mail and prepare reply drafts on request. Jarvis does not request full mailbox access and does not delete mail.
  • Basic profile: the account's email address, to show which account is connected.

How the data is used

  • To answer the owner's requests in the Jarvis terminal and in local notifications (for example, a daily brief of today's events).
  • When the owner asks about their calendar or mail, the relevant content is included in the conversation with the AI model that powers Jarvis (OpenAI, through the owner's own ChatGPT account). It is sent only for that request.
  • Account numbers, card numbers, ID numbers (such as tax file, Medicare, passport and driver licence numbers) and passwords are removed before anything is sent to the AI model — including partial numbers such as "card ending 1234". This is done by Jarvis's own code on the owner's computer, not by asking the model. Jarvis never stores them, not even in part.
  • Jarvis cannot make payments or sign in to banks; it only reminds the owner about bills and events.
  • Google data is not sold, not used for advertising, and not shared with anyone else.
  • Google data is not used to develop, improve or train generalised AI or machine-learning models.

Storage and security

  • The Google sign-in token is stored only on the owner's computer, encrypted with Windows Data Protection (DPAPI) so that only the owner's Windows account can read it. It is never written to logs.
  • Short-lived access tokens are kept in memory only.
  • Jarvis does not keep a copy of the owner's calendar or mailbox. Conversation history stays in the owner's local Jarvis data folder.

Removing access and data

  • Run /disconnect google in Jarvis: this revokes access at Google and deletes the local token.
  • Access can also be removed at any time from Google Account → Third-party connections.
  • Deleting the local Jarvis data folder removes everything Jarvis has stored.

Google API Services User Data Policy

Jarvis's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
