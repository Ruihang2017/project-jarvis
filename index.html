Jarvis

A personal terminal assistant for one person, running on their own Windows computer.

What it is

Jarvis is a private, single-user command-line assistant. It is not a hosted service, it has no servers, and it is not offered to the public. It runs only on its owner's computer and acts only for its owner.

What it does with Google

When the owner connects their own Google account, Jarvis can:

  • Google Calendar — read upcoming events and create or update events the owner asks for.
  • Gmail — read messages to summarise them and prepare reply drafts. Drafts are only sent after the owner confirms.

Jarvis asks only for the permissions a feature needs, and the owner can disconnect at any time.
